# Sketchpad Basic

Sketchpad Basic is a lightweight visual communication tool for creators. Draw a rough idea, add a note, and copy the result into ChatGPT so the visual intent is easier to understand than words alone.

## Features

- Pen, eraser, text, and shape tools
- Neon pink default color for visual emphasis
- Separate color memory for each tool during the browser session
- Undo, redo, clear, zoom, and pan
- Paste images from the clipboard with move, size, and rotation controls
- Image placement preview with anchor/reposition workflow
- Optional notes with quick suggestions and custom text
- Permanent guidance in copied images telling ChatGPT how to interpret the sketch
- Copy-to-Chat workflow that creates a single PNG containing the sketch and notes
- Save and Save As PNG export

## Privacy

Sketchpad Basic is a local browser-based plugin. Drawings and notes stay in the local session unless the user explicitly copies, saves, or pastes them elsewhere. It does not require an external account or server connection.

## Basic workflow

1. Draw or paste an image onto the canvas.
2. Use pink marks to highlight the most important areas.
3. Add a short note or choose a suggestion.
4. Click Copy to Chat and paste the resulting image into ChatGPT.
